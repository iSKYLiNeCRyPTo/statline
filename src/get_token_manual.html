Get a New Token

Regenerate MS_REFRESH_TOKEN and SPARTAN_TOKEN for StatLine.

Run this file locally, not on a server. Everything below happens in your own browser and talks directly to login.live.com / xboxlive.com / halowaypoint.com — no token ever passes through StatLine or any third party. Sign in with the Microsoft/Xbox account that owns the Halo Infinite profile you want StatLine to use as its service account. If a different Microsoft account is already signed in on this browser, use a private/incognito window first.

1 Sign in with Microsoft

Opens Microsoft's login page in a new tab. After you sign in, it will redirect to a blank-looking login.live.com/oauth20_desktop.srf page — that's expected.

Before clicking sign-in, open DevTools (Cmd/Ctrl+Option+I) in that tab and switch to the Network panel first. Microsoft's page scrubs the code param out of the visible address bar via JS a moment after it loads (hence "not normally shown" / "will never ask you to copy this URL") — copying from the address bar after the fact will give you a URL with the code already stripped. Instead, after the redirect, find the oauth20_desktop.srf request in the Network panel, open its Headers, and copy the Request URL shown there — that's the real one with code= still in it.

Paste that Request URL (or just the code= value) here. This code is single-use, so the next step always gives you a command to run yourself rather than trying (and possibly burning it) in-browser first:
